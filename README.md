# OpenAI-Chatbot

This project is designed to scrape data from websites, generate embeddings for textual data, and integrate with OpenAI's API to build intelligent assistants. The project uses Selenium, BeautifulSoup, pandas, and OpenAI's API, among other tools.

## Features
1) Web Scraping:
- Extract product and blog information from specified categories.
- Export data to JSON files for further processing.

2) Embedding Generation:
- Generate embeddings for text data using OpenAI's embedding API.
- Aggregate embeddings for large datasets.

3) Assistant Integration:
- Build a chatbot using Gradio for interactive user conversations.
- Create and customize assistants with OpenAI's platform.

## Requirements
- Python 3.7+
- Selenium
- BeautifulSoup
- pandas
- numpy
- OpenAI API
- Gradio
- tiktoken

## OpenAI API Key

To use OpenAI's API, you must obtain an API key and add it to your user environment variables
- Visit this page for more info: https://platform.openai.com/docs/quickstart
